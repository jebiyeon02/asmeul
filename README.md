# ASMEUL 아스믈 · ASMR Mixer 1.0

아스믈은 여러 환경음을 겹치고 음악에 공간감과 온기를 더하는 macOS용 앰비언트 오디오 믹서입니다.

## 1.0 디자인

- 선택한 사운드 카드는 고정된 금색 테두리 대신 인디고·시안·웜 라이트가 천천히 흐르는 활성 애니메이션으로 표시됩니다.
- macOS 26에서는 SwiftUI Liquid Glass의 `glassEffect`와 애니메이션 `MeshGradient`를 사용합니다.
- 배경은 인디고·퍼플·웜 오렌지 광원이 천천히 교차하며, 광원과 파티클의 갱신 주기를 분리했습니다. 카드 표면은 낮은 투명도의 글래스로 빛을 통과시킵니다.
- 사진 업로드 대신 심해의 휴식·오로라·스펙트럴 무드를 선택할 수 있습니다. 선택한 음원에 맞춰 빗줄기, 파도선, 바람결, 동굴 메아리, 반딧불이, 물속 기포, 라디오 파형, 키 입력, 연필 획, 도시 불빛, 차임 스파클, 모닥불 불씨, 낙엽이 배경에서 움직입니다.
- 별도 `설정` 창에서 배경 및 음원별 파티클 애니메이션을 끌 수 있습니다. 끄면 TimelineView와 Canvas 업데이트를 중지하고 정적 무드 배경만 남깁니다.
- SF Symbols의 반복 효과와 숫자 전환 애니메이션으로 재생 상태를 즉시 보여줍니다.
- macOS 14.4–15에서도 반투명 Material 기반 화면으로 실행됩니다.

공간 선택을 제거하고 원하는 ASMR을 여러 개 동시에 재생하는 macOS 앱입니다. 음악 효과 **Space · Warmth · Orbit**은 유지했습니다.

## 렌더링 및 UI 최적화

- 몰입 사진은 화면 크기에 맞춰 백그라운드에서 미리 디코딩합니다. 전체 화면은 최대 4096px, 미리보기는 512px로 제한하고, 캐시는 96MiB 비용 한도로 관리합니다. 사진 원본은 그대로 보존합니다.
- 사진의 확대·이동은 Core Animation이 처리하며, 매 프레임 사진과 명암 레이어 전체를 다시 그리던 `drawingGroup`을 제거했습니다. 사진이 교체되거나 화면 크기가 달라질 때만 새 이미지가 필요합니다.
- 메인 화면과 몰입모드의 파티클은 최대 120fps 일정, 메인 화면의 광원은 최대 60fps 일정을 사용합니다. 실제 프레임률은 디스플레이와 시스템 부하에 따라 달라집니다.
- 메인 화면의 카드·사이드바·하단 바는 유리 효과를 유지합니다. 많은 슬라이더가 있는 메인 화면에서는 막대와 손잡이만 직접 그려 창 활성화 시의 렌더링 부담을 줄입니다. 드래그·값 전달·접근성은 AppKit 슬라이더를 사용하며, 몰입 모드의 슬라이더는 기존 구현을 유지합니다.
- 재생 정지·창 가림·최소화 시 움직임을 멈추고, 다시 보이면 멈춘 지점부터 이어갑니다. 애니메이션 끄기 및 macOS 동작 줄이기 설정도 반영합니다. 선택하지 않은 카드의 반복 심볼 효과는 실행하지 않습니다.
- 몰입모드는 창의 실제 전체화면 공간을 사용합니다. 초기 창 크기만 1080×720으로 지정하고 전체화면에서는 콘텐츠가 화면 전체로 확장됩니다. macOS 초록색 전체화면 버튼과 앱의 `몰입` 버튼을 모두 지원하며, 몰입 중 `Esc`로 돌아옵니다. 일반 창에서는 빨강·노랑·초록 트래픽 라이트를 사용할 수 있습니다.
- 음량계만 별도 관찰 객체로 갱신하고, 사용하지 않는 콜백 수 알림과 변경 없는 출력 장치·앱 목록 알림을 제거했습니다. 트랙 변경은 바뀐 트랙만 엔진에 전달하며, 전체 해제와 믹스 복원은 묶어서 처리합니다. 연속 저장 요청은 250ms 동안 합치고 종료 시 즉시 저장합니다.

실측 내용과 조건은 [PERFORMANCE_NOTES.md](PERFORMANCE_NOTES.md)에 있습니다.

## 이전 인터페이스와 기능

어두운 안개빛 배경, 반투명 글래스 카드와 2열 사운드 목록을 사용합니다. 왼쪽 패널에는 입체음향·음악 효과·입력 소스를, 하단에는 재생·ASMR 전환·출력·A/B를 배치했습니다. 기존 음원 선택, 음량, 입체 위치·거리, MP3 추가 기능은 유지됩니다. 제공받은 이미지를 macOS 다중 해상도 ICNS 앱 아이콘으로 등록했습니다.

- 24개 소리를 중복 선택하고 각 소리의 음량을 독립적으로 조절합니다.
- 처음 설치하면 빗소리 1, 일본 배경음 1, 키보드 1이 기본으로 선택되어 재생 버튼을 바로 사용할 수 있습니다. 이후에는 사용자가 저장한 선택 상태를 복원합니다.
- 저주파 시네마틱 드론 두 개를 `심우주1`, `심우주2`로 추가했습니다.
- 눈 밟는 소리를 추가했으며, 선택하면 눈송이가 위에서 아래로 내리는 배경 애니메이션이 표시됩니다.
- 파도 1·2, 모닥불 1·2, 지저귀는 새소리, 매미, 물속 소리를 추가했습니다.
- 메인 창의 `MP3 추가`에서 최대 11개의 개인 음원을 가져올 수 있습니다. 파일은 Application Support의 `ASMEUL/User Sounds`에 복사되고 이름·입체음향 위치·거리·음량과 함께 다음 실행에도 유지됩니다. 각 파일은 최대 60분이며, 사용자 음원 카드를 우클릭(또는 Control-클릭)해 표시 이름을 변경하거나 앱에 복사된 파일과 목록을 삭제할 수 있습니다. 기본 음원은 삭제할 수 없습니다.
- 타이머 기능은 제거했습니다.
- 빗소리 1 / 2, 키보드 1 / 2, 연필 소리 1 / 2로 기존 소재와 추가 소재를 구분합니다. 2번은 이번에 제공한 파일입니다.
- 종 소리 1은 제공받은 `hums-wind-chimes-183557.mp3` 원본입니다. 기존의 나무 소리는 포함하지 않습니다.
- 일본 배경음 1은 제공한 japan_background.mp3 원본입니다. 별도 음악이나 합성 DJ를 추가하지 않습니다.
- 빗소리 2는 약 15분 33초 전체를 재생합니다. 각 파일은 끝부분을 최대 0.8초 크로스페이드해 반복합니다.
- 음악 / ASMR 전체 음량, ASMR만 듣기, 원음 듣기와 믹스 저장·불러오기를 지원합니다.
- 입력 소스를 바꿔도 ASMR 선택·음량과 재생 상태를 유지합니다. 앱별 입력은 해당 앱의 오디오 보조 프로세스를 함께 연결하고, 보조 프로세스가 재시작되면 연결을 갱신합니다.
- 음악 입력과 ASMR 출력은 독립적으로 동작하므로 선택한 앱이 일시 정지되거나 무음이어도 ASMR은 계속 재생됩니다.
- `ASMR만`이 켜진 상태에서 특정 앱을 선택하면 해당 앱의 음악 입력을 자동으로 켜고, 음악 효과가 묵음으로 남지 않도록 안내합니다.
- 앱을 시작하고 소리 카드를 여러 개 선택하면 함께 들립니다. Space/Warmth/Orbit은 입력 음악에 적용됩니다.

## 0.6 ASMR 바이노럴 입체음향

헤드폰용 입체음향 스위치와 ASMR별 7방향(앞·좌우 앞·좌우 뒤·뒤·위), 거리 조절을 추가했습니다. 일반 스테레오 원본을 모노 음원으로 배치하고 측정된 양 귀 HRIR을 컨볼루션합니다. 스위치를 끄면 원본 스테레오로 부드럽게 돌아갑니다. 여러 ASMR의 위치와 거리는 믹스와 함께 저장됩니다.

기본 배치: 물결 앞, 풀벌레 왼쪽 뒤, 바람 위, 종 오른쪽 뒤. 황혼 호숫가 레퍼런스의 주변 환경음 느낌을 목표로 한 배치이며 영상 22:14를 직접 청취하거나 동일하게 재현한 것은 아닙니다. 영상 음원은 사용하지 않습니다. 사용자는 원하는 소리를 선택해 조합합니다.

측정 자료: Bill Gardner and Keith Martin, MIT Media Lab, Copyright 1994 MIT Media Laboratory. https://sound.media.mit.edu/resources/KEMAR.html. 번들 HRTF-CREDITS.txt에도 출처·조건을 포함했습니다. 44.1kHz 128탭 응답을 장치 샘플레이트로 재샘플링하며 좌측 방향은 귀 응답을 반전합니다. 개인별 귀 모양에 따른 앞뒤 혼동 가능성이 있고 헤드 트래킹은 없습니다. 거리는 음량·직접음/반사음 비율의 상대적 표현입니다. Space/Warmth/Orbit은 입력 음악 전용이며 이번 HRTF는 ASMR별로 적용됩니다.

## 0.5 효과 강화

- Space 범위 0–100, 8개 지연선이 잔향을 서로 확산하는 피드백 네트워크로 교체했습니다. 높은 값일수록 잔향량과 길이가 늘어납니다.
- Warmth는 고역 감쇠와 부드러운 포화로 음색 변화를 강화했습니다.
- Orbit은 낮은 값부터 이동 폭이 드러나고 최대에서는 좌우를 크게 오갑니다.
- 세 효과는 입력 음악에만 적용됩니다. ASMR만 듣기에서는 효과가 들리지 않습니다.
- 0으로 설정한 효과의 투명성, 긴 잔향, 고역 감쇠, 좌우 이동, A/B와 출력 상한을 자동 검사했습니다.

## 실행 및 검증

`build/ASMEUL.app`을 엽니다. macOS 14.4 이상, Apple Silicon용입니다. 시스템 오디오 접근이 필요합니다.

소스 빌드: `./scripts/build.sh` · DSP/믹서 및 렌더링 회귀 검사: `./scripts/test.sh` · 실제 파일 디코딩 및 40초 믹스 렌더링: `./scripts/previews.sh`.

Mac App Store 제출용 샌드박스 앱과 PKG 생성 방법은 [APP_STORE_SUBMISSION.md](APP_STORE_SUBMISSION.md)에 있습니다.

제공 파일은 원본을 수정하지 않고 앱 리소스로 복사했습니다. 긴 파일을 전체 디코딩하므로 시작 시 준비 시간과 메모리가 필요합니다. 여러 소리를 크게 겹치면 최종 피크 제한으로 왜곡이 생길 수 있어 개별 음량을 낮춰 조절하세요.

기존 소재 출처는 SOUND_CREDITS.md에 있습니다. 이번에 제공한 네 파일은 사용자 제공 소재이며 기존 CC0 표기에 포함되지 않습니다.
